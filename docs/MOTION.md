# RoomDeck 动效规范与实现

2026-09-10。延续暖白、深绿的轻简界面，通过位置连续性和短反馈增强操作感，不增加全屏装饰循环或随机运动。

## 动作与节奏

| 场景 | 动作 | 时长 / 触发 |
| --- | --- | --- |
| 页面标题、表单首次出现 | 8px 上移并淡入 | 240ms，仅进入时 |
| 房间卡片 | 指针悬停抬起 3px，箭头沿右上方向移动 2px | 220–240ms，离开归位 |
| 照片预览 | 轻微放大到 1.025 | 240ms，仅精确指针悬停 |
| 按钮 | 按压缩放到 0.97，释放恢复 | 140ms |
| 一级导航 | 选中底色从当前位置移动到新选项 | 240ms，可连续中断并重新定位 |
| 内容 / 投屏 / 游戏 | 与导航顺序一致的 10px 横向进入 | 240ms；不会因后台同步重复播放 |
| 桌面弹窗 | 12px 上移，0.975 → 1 缩放并淡入 | 260ms |
| 手机弹窗 | 从底部 32px 位移进入 | 260ms |
| 弹窗退出 | 桌面下移 8px / 手机下移 24px，淡出 | 180ms，完成后释放焦点与背景锁定 |
| 页面通知 | 从顶部 8px 位移进入，原路退出 | 进入 220ms / 退出 140ms |
| 上传进度 | 实际进度使用 scaleX 插值 | 180ms，不伪造进度 |
| 上传成功 | 勾号短促放大再落定 | 260ms，一次 |
| 骰子结果 | 轻微旋转、位移与缩放落定 | 320ms，仅真实结果到达后，不显示假点数 |
| 私密词语 | 轻微淡入 | 160ms；隐藏立即生效，避免退出动画延长泄露窗口 |

主要缓动为 `cubic-bezier(.22, 1, .36, 1)`。动作前段及时响应，后段减速停止；退出比进入快。

## 结构与约束

- `web/src/motion.css`：按钮、卡片、提示、上传、结果反馈，及键盘与 reduced-motion 路径。
- `web/src/motion.ts`：输入方式识别、减少动态效果偏好、可取消的页面片段进入。以语义键触发，避免轮询时反复动画。
- `MotionNav.vue`：测量目标位置，以 transform 动画移动选中背景。切换中再次点击时，读取当前视觉位置并重定向；尺寸或语言变化直接重新定位。
- `Modal.vue`、`DialogTransition.vue`、`dialogMotion.ts`：原生 dialog 保持在顶层完成退出。动画不改变后台提交时序，提交结果仍立即处理。关闭后释放页面锁定并恢复焦点。
- 主导航移到内容标题上方，切换区域时其位置固定。投屏和游戏组件保留挂载，动效不会重新建立媒体连接。

移动只使用 transform 与 opacity；不对 width、height、top、left 做动画。不使用 `transition: all`，不长期设置 `will-change`，没有新增动画运行库或外部字体、图片请求。

## 无障碍与测试

系统启用 `prefers-reduced-motion: reduce` 时取消位移和动画；设置在运行中变化时也取消当前动画。键盘触发操作即时切换，焦点状态仍清楚；恢复指针操作后恢复普通动效。窗口隐藏时取消运行中的动画，不持续后台循环。悬停效果只作用于支持精确指针的设备。

`web/tests/motion.spec.ts` 检查快速切换后的选中背景位置、导航不跳动、260ms 弹窗进入与 180ms 退出、背景锁释放，以及减少动态效果和键盘路径。原有 UI 检查在有限动画结束后扫描对比度，避免将渐显过程中的透明度当作最终颜色。

实际录屏见 `ui-motion.html`。录屏中的短暂停留仅为了看清动作，不是应用延迟。手机录屏使用 Chromium 手机尺寸视口，尚未替代真机触摸与 Safari 测试。

最终验证：生产构建通过；343 个双语键一致；10 项端到端测试全部通过（39.8 秒），包含原有照片、投票、导出、游戏与真实多人投屏。桌面录屏 1280×900、约 9.5 秒；手机录屏 390×844、约 6.6 秒，采集无页面脚本错误。导航动画读取到 240ms transform 关键帧，并检查了中间位置；没有 width/height/top/left 过渡或永久 will-change。
